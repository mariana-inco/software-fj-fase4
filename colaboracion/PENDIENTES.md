## Cómo cerrar una actividad

1. Realizar el trabajo o la revisión y comprobar el resultado.
2. Registrar fecha, participante, actividad, archivos revisados, comando y resultado
   en SEGUIMIENTO.md. Si no hubo cambios, indicar qué se comprobó.
3. Marcar la casilla correspondiente y vincular el commit, pull request o evidencia real.
4. Hacer commit de cambios concretos con la cuenta de quien los realizó y la fecha real.

No es necesario generar un commit por obligación cada día. Una revisión puede
quedar documentada en la bitácora. Si no hubo actividad, la tarea continúa pendiente;
no se registra como terminada ni se modifican fechas para simular su realización.
